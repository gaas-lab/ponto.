# Templates de e-mail do Supabase

## Redefinição de senha

- Assunto: `Vamos criar uma nova senha para sua conta do Ponto?`
- HTML: `reset_password.html`

Cole o assunto e o conteúdo do arquivo em **Authentication → Email Templates → Reset Password** no painel do Supabase. O envio passa a usar o template depois de salvar no painel.
